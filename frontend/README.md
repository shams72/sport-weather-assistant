### Start By

```bash
cd cook-book
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

The application will then be available at the URL shown in the terminal, typically:

```text
http://localhost:5173
```

### Start the Backend

Start the backend using the instructions in the `backend` directory.

Make sure the backend is running before sending queries from the application.

> **Note:** The first query may take up to **2 minutes** to receive a response after the backend has started. Subsequent queries may take up to **1 minute** each.
